## Relationship Summary

| Parent Table | Child Table    | Relationship | Foreign Key     | Delete Action |
|--------------|----------------|--------------|------------------|--------------|
| users        | listings       | 1-to-many    | listings.user_id | CASCADE      |
| listings     | listing_views  | 1-to-many    | listing_views.listing_id | CASCADE |

## Index Strategy

| Table        | Column(s)              | Type      | Purpose                        |
|--------------|------------------------|-----------|--------------------------------|
| users        | id                     | Primary   | Unique user identification      |
| users        | email                  | Index    | Fast email lookup (optional)    |
| users        | phone                  | Index    | Fast phone lookup              |
| listings     | id                     | Primary   | Unique listing identification   |
| listings     | slug                   | Unique   | SEO-friendly URL lookups       |
| listings     | brand                  | Index    | Filter by brand                |
| listings     | status                 | Index    | Filter by approval status      |
| listings     | created_at             | Index    | Sort by newest                 |
| listings     | user_id                | Index    | Get user's listings           |
| listings     | brand, model           | Composite | Combined filter               |
| listings     | status, created_at      | Composite | Approved listings by date      |
| listing_views| listing_id             | Index    | Get views for a listing        |
| listing_views| view_date              | Index    | Get views by date              |

## Data Types Reference

| Column         | Type                    | Notes                                |
|----------------|-------------------------|--------------------------------------|
| id             | UUID                    | Primary key, auto-generated            |
| user_id        | UUID                    | Foreign key to users table             |
| listing_id     | UUID                    | Foreign key to listings table           |
| slug           | VARCHAR(255)            | Unique, SEO-friendly URL              |
| price         | INTEGER                 | Store in cents/pesos, no decimals      |
| images        | TEXT[]                  | PostgreSQL array for image URLs         |
| status        | VARCHAR(20)            | Enum: pending/approved/rejected       |
| created_at    | TIMESTAMP WITH TZ       | Auto-set on insert                     |
| updated_at    | TIMESTAMP WITH TZ       | Auto-updated on change                 |
| view_date     | DATE                    | Date only, for daily aggregation       |
| view_count    | INTEGER                 | Counter for the day                   |
